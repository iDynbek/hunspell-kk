# Kazakh spelling dictionary (kk_KZ)

Generated Hunspell dictionary for Kazakh: 131,289 entries, two-level affix
rules covering the full nominal and verbal inflection grids, suggestion tables
for the Russian-for-Kazakh letter confusions (о/ө, н/ң) and the Latin
look-alikes legacy fonts leave behind (үшiн → үшін).

On a million words of held-out Kazakh news prose it accepts 98.1% of tokens /
95.4% of types (the 2009 dictionary previously in circulation: 82.1% / 58.2%).
The measurements are reproducible from the source repository.
