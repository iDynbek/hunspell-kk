# extensions.libreoffice.org listing

**Name:** Kazakh Spelling Dictionary — Қазақша емле сөздігі
**File:** dist/kk_KZ.oxt (or the release asset)
**Categories:** Dictionary
**Tags:** kazakh, kk, kk-KZ, spelling, spellcheck, қазақша, емле

**Short description:**
Spelling dictionary for Kazakh (kk-KZ). Accepts 97.9% of real Kazakh text
where the widespread 2009 dictionary accepts 82%, with full nominal and
verbal inflection.

**Install note (put in the description):**
Install via Tools → Extension Manager → Add. Do not double-click the .oxt on
the Flatpak build of LibreOffice — a LibreOffice bug crashes it when opening
any extension file directly; the Extension Manager menu is unaffected.

**Long description:**
Kazakh is agglutinative: мектептерімізде is мектеп plus plural, possessive
and locative, and a dictionary that allows only one suffix per word — as the
2009 kk_KZ that has circulated ever since does — ends up underlining two
correct words in three. This dictionary generates the suffix chains the
language actually uses.

Measured on a million words of Kazakh news text it accepts 97.9%, flagging
about one word in 48; the complete nominal and verbal inflection grids are
covered. It knows the proper names of Kazakhstan — Тоқаев, Айзере, Алматы,
inflected — and the official-document spellings of common names.

Made by an individual volunteer for the free use of the Kazakh language on
the internet. GPL-3.0-or-later. Sources, methodology and measurements:
https://github.com/iDynbek/hunspell-kk
Report wrongly underlined words or missed misspellings:
https://github.com/iDynbek/hunspell-kk/issues
